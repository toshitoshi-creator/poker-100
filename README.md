# Poker 100 Survival — カード演出プロトタイプ

スマートフォン縦画面向けのテキサスホールデム × 100人サバイバルの演出プロトタイプ。

```bash
npm install
npm run dev        # http://localhost:5173 (?seed=123 で乱数シード固定)
npm run typecheck
npm test
npm run build
npm run build:single  # 1ファイルの HTML（スマホ配布用）→ dist-single/
```

## ルール（HP＝チップ、テキサスホールデム）

- 卓の人数はロビーで選択：**1対1（標準）** または **6人卓**。選択は端末に保存され、URL の `?table=6` でも指定できる
- あなたは画面下、相手は100人の中から着席（1対1は上に1人、6人卓は上3人・左右2人）。ディーラーボタンは毎ハンド時計回り
- 1対1ではボタンが SB を払い、プリフロップは先に行動する（通常のヘッズアップのルール）
- ブラインド制（SB/BB）。BB は 2 から始まり 4 ハンドごとに +2
- ベットはプリフロップ・フロップ・ターン・リバーの4回。フォールド / チェック / コール / ½ポット / ポット / オールイン
  - レイズは1ストリート4回まで（最小レイズ額あり）。オールインが絡むとサイドポットに分かれる
- フォールドすると、それまで賭けた分に加えて **フォールドダメージ（4＋BB）** を受ける（誰の物にもならず消える。AI も同じ）。ずっと降り続けて順位だけ上げる戦法を防ぐため
- 勝者はポットの HP を奪う。ショーダウンで単独トップの役を作ると、ショーダウンに残った全員に役ボーナスダメージ（`logic/combat.ts` の `HAND_BONUS`）
- HP 0 で脱落。空いた席には他の卓の生存者が座る（持ち HP 60〜120）。最後の 1 人になれば勝利
- 相手 AI は自分の手札と見えている場札だけで判断（`logic/ai.ts`：複数人相手のモンテカルロ勝率＋ポットオッズ）。シード乱数でブラフもする

## 設計

**ゲーム結果は先に確定し、演出はそれを表示するだけ。**

| 層 | 場所 | 役割 |
| --- | --- | --- |
| ロジック | `src/logic/` | 純粋関数のみ。DOM / GSAP 非依存 |
| 操作 | `src/game/controller.ts` | 「配る」「ベット」などの操作ごとに純粋関数（`startHand` / `playerAct`）で状態を確定。演出中なら先にスキップ |
| 演出 | `src/presentation/director.ts` | ロジックが出したイベント列を GSAP で再生。`view.ts` の純粋なリデューサーで「この時点の盤面」を求め、開始時・スキップ時・終了時はそこへスナップする |
| 表示 | `src/ui/` | レイアウトのみ。動きは `data-*` 属性経由で Director が付与 |
| 効果音 | `src/audio/` | ID ベースの `SoundBus`。`soundMap.ts` にファイルを登録すれば鳴る |

ロジック関数:

- `logic/deck.ts` — 52枚デッキ生成・Fisher–Yates シャッフル・重複検査
- `logic/handEvaluator.ts` — 7枚から最強の5枚を直接判定（ホイール含む）・比較。総当たり版と3万ハンドで一致をテスト
- `logic/combat.ts` — ダメージ計算と演出ティア
- `logic/hp.ts` — HP 更新・脱落判定
- `logic/game.ts` — ハンド進行（1対1／6人卓）・サイドポット・席の補充（同じシード＋同じ操作 → 同じ結果）
- `logic/ai.ts` — 相手の判断（モンテカルロ勝率＋ポットオッズ）

## 演出

- 配布は 1 枚ずつ時差、`power3.out` で山札から飛ぶ
- 反転は Y 軸 0→90° でフェイスを切り替え → 90→180°（`backface-visibility` と併用し表裏が同時に見えない）
- フロップ → ターン → リバー → ショーダウンの順
- 役のティア 0〜4 で粒子数・画面揺れ・フラッシュ・バナー装飾が段階的に強くなる
- 攻撃エフェクト → 被弾揺れ → ダメージ数値 → HP の数値とバーを同じ値から描画 → 脱落スタンプ
- `prefers-reduced-motion` 時は移動・揺れ・粒子なし、短いフェードのみ
- 再生速度 ×1/×2、スキップ、リプレイ
- 開始時は100人の画面（10×10）を表示し、自分の席へズームインしてテーブルへ
- 上部の「生存者」をタップすると自分の席からズームアウトして100人の生存状況（今回の脱落は×が押される）を表示
